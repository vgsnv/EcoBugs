# План: отрисовка мира 1 — слои и WebGL2

Дата: 2026-10-04. Относится к `world-1` (развиваемая версия; `world-2` отложен). Прежний вариант этого плана (2026-10-03, перенос всей картинки разом) заменён: переход делается по слоям, картинка не ломается целиком ни на одном шаге.

## Зачем

- Впереди работа над показом течений и круговорота минерала. Это попиксельные анимированные поля — естественная задача для шейдеров; на Canvas 2D они дороги и сложны.
- Замер 2026-10-04 (production, сид 1, 1205×1018 при DPR 2): обычный кадр стоит 5–6 мс, после нового снимка мира — около 12 мс; на ×100 и быстрее 5–12% кадров приходят позже 25 мс. Причины — перестройка слоя минерала на CPU и фильтры `blur` в свете.
- Вся картинка — один класс `render.ts` (~2070 строк): правка одного эффекта задевает остальное.

## Принятые решения

1. Рефакторинг (шаг 1) сохраняет картинку пиксель в пиксель; это проверяется отпечатками кадра (`?check`).
2. При переносе на WebGL2 (шаг 2) небольшие отличия картинки допустимы: точная копия Canvas-фильтров не нужна, эффекты всё равно будут переделываться.
3. WebGL2 обязателен; запасного пути на Canvas 2D нет. Без WebGL2 страница сообщает об этом.
4. Физика, Worker, сохранения и интерфейс панелей не меняются.

## Устройство кадра (после шагов 1–2)

Два холста одного размера. Нижний — WebGL2 (`render/field.ts`), верхний — прозрачный Canvas 2D.

| Слой | Где | Как |
| --- | --- | --- |
| Тень чашки на столе | WebGL | Аналитически: фигура, размытая гауссом (`erf`) |
| Местность (камень, трещины, зерно, вода, отмель, залежи, кристаллы, берег) | WebGL | Шейдер `terrainAt` (`render/terrain.ts`): те же правила, что были на CPU; данные — сетки уровня и залежей и неизменные на мир узоры. Плиток и перерисовки блоков больше нет |
| Пятна света | WebGL | Эллипсы из модели (`spotShapes` в ядре) рисуются прямоугольниками в маску с наложением «максимум»; мягкий край — `erfc` от расстояния до волнистой границы |
| Свет, рябь по течениям, пена, мутность и дымка минерала | WebGL | Один полноэкранный проход полей |
| Отверстия воронок, свечения жерл, вспышки залпов, свечение недр, искры, блёстки | WebGL | После полей, в порядке вызовов; свечения — режимом «screen» |
| Зёрна минерала, жерла, приток, крупинки воронок, процессы, стекло, проба, линейки | Canvas 2D | Как прежде |
| Мини-карта | Canvas 2D | Уменьшенная подложка местности на CPU — по частям и только когда карта видна |

## Шаг 1. Рефакторинг на слои (картинка не меняется)

- `render/camera.ts` — масштаб, центр, вписывание, перевод экран ↔ мир, `px`.
- `render/palette.ts` — цвета и общие функции (`mix`, `smoothstep`, `rgb`, `lightTone`).
- Слои — отдельные файлы `render/*.ts` с общим кадром (`Frame`: холст, камера, мир, время анимации, шаг течений, проявленность деталей, сила света):
  `terrain.ts` (подложка, плитки, перерисовка блоков, маска воды), `light.ts`, `water.ts` (рябь, пена, блёстки), `mineral.ts` (мутность, дымка, зёрна), `sources.ts` (извержения, жерла, приток, воронки), `walls.ts` (тень чашки, стекло, перегородки), `processes.ts`, `minimap.ts`.
- `render.ts` — только порядок слоёв и внешний интерфейс `WorldRenderer` (он не меняется для `main.ts`).
- Проверка: отпечатки `?check` до и после совпадают во всех сценах, без исключений.

## Шаг 2. Нижний холст WebGL2

Выполнено (2026-10-04); в деталях — иначе, чем задумано ниже: местность сразу считается в шейдере, а пятна — маской по эллипсам без `blur`. Итог — в «Устройстве кадра».

Под Canvas 2D — холст WebGL2 того же размера; верхний холст прозрачен там, где нет объектов. Переносится по одному слою, после каждого — проверка глазами и `?check` (отличия ожидаемы только в перенесённом слое).

1. Основа: контекст, программа полноэкранного прохода, текстуры полей, камера как матрица; обрезка по чашке в шейдере. Потеря контекста — восстановление ресурсов.
2. Местность: подложка и плитки загружаются текстурами по мере построения (CPU-построение пока остаётся).
3. Минерал: поле 200×150 (Float32) — текстура при каждом новом состоянии мира; сглаживание, мутность и цвет — в шейдере. Уходят рывки от перестройки слоя.
4. Свет: пятна считаются в шейдере по параметрам эллипсов (`blobShape` ядра) — тень, тёплый оттенок, высветление и мутность одной формулой; `blur` больше не нужен.
5. Вода: рябь по течениям — в общем контексте (поле течений — текстура), пена и блёстки — там же.

После шага 2 Canvas 2D рисует только объекты; новые виды течений и минерала делаются сразу в шейдерах.

## Шаг 3 (по необходимости)

Местность на GPU целиком (камень, трещины, залежи), объекты — инстансами. Делается, когда до этих слоёв дойдёт работа.

## Проверки

- `?check` в адресе страницы: `renderCheck.all()` строит сцены (сиды 1 и 3, вся чашка, извержение ×8, воронка ×6 с процессами) и даёт отпечатки; `renderCheck.compare(до, после)` показывает отличающиеся сцены и плитки.
- Производительность: время JS кадра и интервалы кадров по реальным часам на ×1, ×1000, ×10000, вся чашка и приближение (как в замере 2026-10-04).
- `npm run build` (TypeScript + сборка).

## Как проверять отрисовку

На странице `?check` (расчёт и анимация не запускаются):

- `renderCheck.all()` / `renderCheck.run(i)` — отпечатки кадров сцен; `renderCheck.compare(до, после)` — какие сцены и плитки изменились (для правок, которые не должны менять картинку);
- `await renderCheck.against('/другая-сборка/index.html?check')` — сравнение с другой сборкой того же адреса по сетке средних цветов (для правок, где допустимы небольшие отличия);
- `renderCheck.timing(i, кадров, шагов, gpu)` — время отрисовки кадра (с `gpu` — до конца работы видеокарты).
