# План: песочница неживой природы

Реализация [спецификации мира](../spec/world.md) в браузере на TypeScript. Существ нет — только мир: чашка, перегородки, вязкость, свет, температура, время. Мир можно сохранить в файл и загрузить из файла.

## Где и как

- Папка `world/` со своими `package.json` и `tsconfig.json`; не трогает RN-приложение, Metro, jest и старое ядро `core/`.
- Сборка и dev-сервер — Vite.
- Рисование — Canvas 2D: поля (свет, вязкость, температура) растровыми слоями, перегородки кривыми.
- Автотестов нет (решение пользователя): проверка — `npm run typecheck` и просмотр в песочнице.

```
world/
  index.html
  src/core/     чистое ядро: без DOM, только правила мира
  src/app/      песочница: холст, панель параметров, время, файлы
```

## Ключевые решения реализации

- **Состояние мира** = параметры + сид + номер шага; всё остальное строится или досчитывается детерминированно.
- **Пятна света — явные объекты**, а не порог шумового поля (у порога пятна сами рождаются и пропадают, нарушая «пятно не исчезает»). Пятно — группа мягких эллипсов с минимальным размером; свет в точке — максимум по эллипсам (яркость не складывается); эллипсы группы медленно расходятся и сходятся (деление и слияние); координаты по модулю размера карты (края сомкнуты).
- **Карта вязкости** — шум; суша по порогу, вокруг неё гарантированное кольцо отмели по полю расстояний, затем размытие границ.
- **Перегородки** — набор готовых заготовок в виде данных: ломаные из горизонтальных и вертикальных отрезков, вершины в долях размера чашки. При создании мира не генерируются; заготовка выбирается параметром «Планировка».
- **Файл мира** — JSON с версией формата: параметры, сид, номер шага, контрольная сумма состояния. При загрузке — проверка версии, диапазонов и контрольной суммы.
- **Числа по умолчанию** — в одном конфиге, настраиваются в песочнице. Для размытых правил («отсеки не бывают крошечными») — предварительные пороги.
- **Ходы существ** в шаге мира — пустая заготовка.

## Этапы

| # | Этап | Результат и проверки |
|---|---|---|
| 0 | Каркас `world/`, Vite | пустой холст открывается |
| 1 | ГПСЧ, шум с сомкнутыми краями, параметры и значения по умолчанию | один сид — один и тот же мир |
| 2 | Карта света: пятна, фон, размытый край, сдвиг с поворотом | пятна не исчезают; свет не складывается; края сомкнуты |
| 3 | Температура | фон = базовая, в пятне = базовая + нагрев; от солнца не зависит |
| 4 | Карта вязкости | вода и суша не граничат напрямую; доли близки к параметрам |
| 5 | Перегородки: набор заготовок и их проверка | в каждой заготовке замкнуты только отсеки; нет крошечных областей; перегородка не пересекает себя |
| 6 | Песочница: слои, параметры, сид, пауза/×1/×10/×100, счётчик шагов | мир видно и можно крутить |
| 7 | Сохранение и загрузка файла | после сохранения и загрузки состояние совпадает; битый файл отклоняется |

## Наглядность

Сделано (вместе с линиями течений); физику мира не меняет. Бюджет кадра нужен будущим существам, поэтому каждое — дёшево по построению.

| Что | Как сделать дёшево |
|---|---|
| Блики на воде | Заранее нарисованная бесшовная текстура ряби (~256 px) со сдвигом по времени; маска воды строится один раз на мир, как плитки местности; блики — только где вода и свет (пересечение масок наложением). Не считать рябь попиксельно в JS. |
| Мини-карта | Только при приближении. Уменьшенная подложка местности (уже есть), маска света в малом разрешении и рамка текущего вида. |
| Направление дрейфа света | Стрелка; направление — из формулы сдвига карты света. |

Отложено: тепловая карта «где был свет» и сводка по отсекам (замеры раз в ~100 шагов).

Снос в песочнице — линии течений как часть пятен света: от точек на внешнем краю каждого пятна (их число у пятна постоянно, они движутся вместе с ним) бегущим пунктиром до конца течения, на конце наконечник. Линии не пропадают, а плавно меняются вслед за светом; прокладка каждый кадр, ~1,5 мс. Поле течений — в ядре (`core/drift.ts`), пересчёт раз в 500 шагов с плавным переходом.

## Минерал в песочнице

- Ядро — `core/mineral.ts`: растворённый минерал на сетке 200×150 (двойная точность), недра, вулканы; слоистость — за обновление течение уносит не больше слоя, пропорционального его силе. Минерал — состояние мира: обновляется раз в 100 шагов на фиксированных шагах (снос за промежуток, осаждение, наступившие извержения), поэтому ход мира не зависит от скорости показа. Перенос сносом сохраняет количество (доли соседних клеток точки назначения; в перегородки не попадает, не перескакивает их).
- Файл мира (v5) хранит поле минерала, недра и расписание вулканов; после загрузки мир идёт так же, как исходный.
- Показ: фиолетовая дымка там, где минерала больше среднего (размыта только для глаза), там же мягкое затемнение от мутности, вулканы — кружки с фиолетовой каймой; пока вулкан извергается, от него расходятся кольца (ярче — сильнее выброс); сводка «в среде / в недрах / извержений»; в подсказке у курсора — плотность минерала и расписание вулкана.
- Бюджет кадра на шаги мира — 24 мс: если мир не успевает за скоростью, он идёт медленнее (отставание не копится), на панели — настоящая скорость и пометка «предел».
