Ядро «залипательности»: мир живёт, пока приложение закрыто.

· 1–2 вечера · риск низкий

### 3-2. Детерминированный догон при resume
Вернулся через час → досчитать пропущенные тики. Фундамент готов (детерминизм + сериализация зелёные).
**Приёмка:** расширить `serialize-test.ts` — догон по времени даёт тот же хэш, что непрерывный прогон.
**Риск:** долгий догон блокирует UI → отсюда следующая задача.
· 2 вечера · риск средний

### 3-3. Кап + локальные уведомления
Реального фонового счёта на мобилке нет — ОС усыпляет процесс. Мир досчитывается при открытии. Ушёл на неделю → миллионы тиков → зависание.

**Решение — кап:** предел досчитываемого времени, дальше мир «замерзает». При уходе в фон планируем локальное уведомление на `now + кап`: «мир остановился, зайди обновить». Вернулся раньше → отменяем.

Это **механика, а не костыль**: у мира есть «завод», который надо подкручивать. Приложение само зовёт назад.
**Приёмка:** ушёл надолго → пришло уведомление → вернулся → экран «пока тебя не было, прошло N поколений».
· 2 вечера · риск низкий

## Фаза 3+ — Глубина эволюции

⚠️ **Обязательно прочитай `PLAN.md` §4а и §4б перед началом.** Здесь две ловушки, где наивная реализация выглядит как баг, но им не является.

### 4-1. NEAT — появление новых генов
**Оценка:** 5–8 вечеров · **Риск: высокий**

Замена `RuleBrain` → `NeatBrain`. Геном мозга — растущая сеть; мутации «добавить узел / добавить связь / изменить вес». **Добавление узла = появление гена, которого никто не задавал.**

Инфраструктура уже готова: интерфейс `Brain` и поле `brainGenome` в геноме и сериализации. **Ядро переписывать не нужно** — если начал переписывать `world.ts`, остановись, ты идёшь не туда.

**Ловушка (PLAN.md §4а):** классический NEAT защищает новизну видообразованием — свежая топология сначала работает *хуже*, ей дают время дозреть. У нас **эмерджентный отбор без функции приспособленности**, защиты нет: мутант с новым бесполезным узлом просто умирает. Открытая эволюция будет **капризнее**, чем на демо канонического NEAT. Это ожидание, а не дефект.

**Критично для детерминизма:** все мутационные выборы — через сидированный PRNG; обход узлов и связей — строго по упорядоченным массивам, не по ключам объектов. Иначе рушится resume.

**Приёмка:** за N поколений средний размер сети растёт, поведение усложняется; `check-invariants.ts` зелёный.

### 4-2. Половое размножение (смешанный мир)
**Оценка:** 4–6 вечеров · **Риск: высокий**

Ген `sexualTendency` (0 = деление, 1 = партнёр). Обе стратегии сосуществуют, способ размножения — **сам объект эволюции**.

**Ловушка (PLAN.md §4б) — «двойная цена секса»:** бесполые плодятся быстрее (не тратятся на поиск партнёра) и в лоб **вытеснят половых за несколько поколений**. Фича самоуничтожится. Это **нерешённая загадка биологии**, а не баг реализации.

Что удерживает секс живым — **меняющаяся среда**. И у нас уже есть катаклизмы: в стабильные эпохи выигрывают быстрые бесполые, ударил ледниковый период — половые, перемешивающие гены, вырываются вперёд. **Система катаклизмов становится двигателем отбора между стратегиями размножения.**

**Возвращает:** innovation-номера в NEAT (нужны для кроссовера; при бесполом не требовались).

**Приёмка:** обе стратегии сосуществуют хотя бы в части конфигов; ледниковый период сдвигает баланс к половым. Доминирование одной стратегии допустимо, **если это наблюдаемый исход, а не следствие бага** — докажи графиком.

## Фаза 4 — Экосистема

### 5-1. Хищники
**4–5 вечеров · риск высокий.** Циклы Лотки–Вольтерры легко роняют мир в каскадное вымирание. Балансировать **только на графиках в headless**, не на глаз.
**Бонус:** решает известный долг — сейчас отбор пережимает размер к минимуму (мелкий дешевле, контрдавления нет). С хищниками крупный станет менее уязвим → появится естественный trade-off.

### 5-2. Климатический планировщик
**3–4 вечера · риск средний.** Экран-таймлайн, куда игрок выкладывает будущие катаклизмы. Механизм есть (`TimelineEvent` с огибающими), нужен UI. **Превращает наблюдателя в режиссёра** — рычаг, ради которого возвращаются в приложение.

### 5-3. Эмбиент
**2–3 вечера · риск низкий.** Следы движения, частицы, день/ночь, подброс корма тапом.

## Порядок

**B-1 → Фаза 2 → Фаза 3 → NEAT → половое → хищники**

Почему так: сначала закрыть белое пятно (RN). Потом сделать эволюцию видимой — иначе непонятно, работает ли глубина, которую добавляешь. Потом фоновую жизнь — это то, ради чего приложение открывают снова. И только затем по **одному** вектору глубины за раз.

**Не бери две высокорисковые задачи одновременно.** Если мир свалится в вымирание после одновременного ввода NEAT и хищников — ты не поймёшь, что виновато, и потеряешь неделю.
