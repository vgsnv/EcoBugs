# GPU-прототип мира

Исследовательский стенд, а не завершённая замена `world`. Требует WebGPU; запасного движка нет. План — `docs/plan/world-gpu.md`.

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5174/. `npm run build` проверяет TypeScript и сборку; `npm run check` — начальные данные. Кнопка «Проверить свет» проверяет реальное GPU-поле, проекцию увлечения, баланс отсеков и повторяемость динамики. В сценах «Дрейф света» и «Свет в закрытых отсеках» есть переключатель движущегося/неподвижного света. Кнопка «Проверить физику GPU» запускает реальные вычислительные проходы и проверки в браузере. «Сравнить решатели» измеряет подготовку давления на одинаковых сценах: прогрев и три прогона с чередованием порядка, проверка невязки и отличия скоростей.

Физический шаг — 0,1 с. Масса учитывается целыми квантами 0,001 мг; остатки переноса хранятся отдельно. Поле давления рассчитывается red-black SOR с коэффициентом 1,95 (1,6 для динамического света) и фиксированным числом итераций для сцены/сетки. Weighted Jacobi оставлен как контрольный алгоритм для сравнения. Скорости лежат на гранях клеток, передача между клетками вычисляется один раз и применяется с противоположными знаками. Отверстие принимает вещество, запрещает выход и возвращает избыток в резервуар. Короткий выброс списывает массу из резервного объёма.

Сцены заданы вручную. Они проверяют вычислительный метод; полного генератора, затухающего поля вулкана, жизненных циклов, диффузии, эрозии, залежей, грунта и сохранений пока нет. Пара «источник/возврат» в стенде не является окончательной моделью вулканов. В статических сценах давление решается при выборе сцены. Световые сцены обновляют поле и проекцию перед каждым десятым шагом, по модельному времени: фиксированные гладкие пятна дрейфуют и деформируются, пересечения используют максимум, солнце меняется по ритму. Средний свет вычитается отдельно в каждом отсеке. Увлечение проецируется на допустимый поток с возвратным движением. Крупные поля не читаются на CPU для кадра или обновления. Карта света пока задана вручную, генератор по сиду впереди.

Сетка круга ступенчатая: её площадь пока приближённая, а масса задаётся сценой, не мировым запасом. Перенос первого порядка размывает пятна; выбор более точного метода остаётся задачей следующего этапа. Целочисленный баланс не доказывает завершённость всей спецификации.
