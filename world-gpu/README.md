# GPU-прототип мира

Исследовательский стенд, а не завершённая замена `world`. Требует WebGPU; запасного движка нет. План — `docs/plan/world-gpu.md`.

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5174/. `npm run build` проверяет TypeScript и сборку; `npm run check` — начальные данные. Кнопка «Проверить физику GPU» запускает реальные вычислительные проходы и проверки в браузере. «Сравнить решатели» измеряет подготовку давления на одинаковых сценах: прогрев и три прогона с чередованием порядка, проверка невязки и отличия скоростей.

Физический шаг — 0,1 с. Масса учитывается целыми квантами 0,001 мг; остатки переноса хранятся отдельно. Поле давления рассчитывается red-black SOR с коэффициентом 1,95 и фиксированным числом итераций для сцены/сетки. Weighted Jacobi оставлен как контрольный алгоритм для сравнения. Скорости лежат на гранях клеток, передача между клетками вычисляется один раз и применяется с противоположными знаками. Отверстие принимает вещество, запрещает выход и возвращает избыток в резервуар. Короткий выброс списывает массу из резервного объёма.

Сцены заданы вручную. Они проверяют вычислительный метод; полного генератора, затухающего поля вулкана, жизненных циклов, солнечного увлечения, диффузии, эрозии, залежей, грунта и сохранений пока нет. Пара «источник/возврат» в стенде не является окончательной моделью вулканов. Статическое давление решается при выборе сцены, не пересчитывается на каждом шаге.

Сетка круга ступенчатая: её площадь пока приближённая, а масса задаётся сценой, не мировым запасом. Перенос первого порядка размывает пятна; выбор более точного метода остаётся задачей следующего этапа. Целочисленный баланс не доказывает завершённость всей спецификации.
