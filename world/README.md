# Мир EcoBugs

Единственный движок чашки: вычисления и изображение на WebGPU. Запасного CPU/WebGL-режима нет. Старый Canvas/CPU-мир заменён; его исходники доступны в Git до коммита принятия.

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5174/. `npm run build` проверяет TypeScript и производственную сборку; `npm run check` — детерминированные генераторы, источники, воронки и целочисленный бюджет. Реальные GPU-проверки находятся в раскрываемом разделе «Проверки и измерения».

Начальная сцена — полный мир по спецификации. Параметры задаются через «Создать новый мир». Доступны круг/прямоугольник, камера, миникарта, линейки, полный экран, карты процессов, скрываемая сводка, ускорение и одиночный шаг. Проверочные сцены используют тот же движок.

Физический шаг 0,1 с. Минерал учитывается целыми квантами; квант выбирается при создании и не меняется. Обмены сохраняют дробные остатки и точную общую массу. Давление — SOR на стандартной сетке 128, многоуровневый метод на длинной стороне от 192 клеток; Jacobi оставлен для контрольного сравнения. Перенос и растекание выбирают внутренние подшаги по устойчивости, не меняя время мира. Выброс теряет собственный импульс, скользит и слабо отскакивает от стен, затем смешивается с поверхностным минералом.

Формат сохранения `ecobugs-gpu-2` содержит все продолжительные поля и автоматы. Старые CPU-файлы и экспериментальный `gpu-1` несовместимы. При потере устройства мир стоит; восстановление возвращает последнюю CPU-точку (снимок раз в 15 секунд реального хода), явно показывая её шаг. Не сохранённый промежуток не достраивается.

Крупные физические поля не читаются на CPU ради кадра. Редкие чтения обслуживают события, сводку, устойчивость и сохранения. Размер сетки и доступная память ограничивают комбинации параметров; слишком мелкие пятна либо неразрешимые доли отклоняются с понятным сообщением.

[Спецификация](../docs/spec/world.md), [план и решение о переходе](../docs/plan/world-gpu.md), [результаты измерений](../docs/reports/world-gpu-app-2026-10-03.md). Выигрыш подготовки изображения подтверждён; двукратное ускорение всей физики относительно прежней версии не подтверждено.
