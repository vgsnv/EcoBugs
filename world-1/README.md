# World 1

Развиваемая CPU/Canvas-версия чашки. WebGPU-версия `world-2` отложена; совместимость с ней (код, сохранения, поведение) не поддерживается.

Запуск из корня репозитория:

```sh
npm --prefix world-1 ci
npm --prefix world-1 run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Время физики по этапам (без браузера): `npm --prefix world-1 run profile`. Показывает, сколько миллисекунд каждый этап занимает в одном обновлении минерала; запускать до и после правок физики. Этапы отмечаются вызовами `phase(...)` из `src/core/profile.ts`; новый заметный этап стоит отметить так же.

Стенд замеров параметров: `npm --prefix world-1 run bench` (опции — в начале `scripts/bench.mjs`). Каждый параметр проходит по точкам своего диапазона на нескольких сидах; снимаются наблюдаемые величины мира (пятна, течения, мутность, доли местности, минерал, события). Отклик сравнивается с собственным шумом мира — разбросом прогонов по умолчанию. Полный прогон — около часа; результаты в `world-1/bench-results/` (не в git), сводка заново: `npm --prefix world-1 run bench -- --report world-1/bench-results/bench.json`.

Отрисовка — WebGL2 (поля) и Canvas 2D (объекты), см. [план](../docs/plan/world-webgl.md). Проверка отрисовки — страница с `?check` в адресе: `renderCheck.all()`, `renderCheck.against(...)`, `renderCheck.timing(...)` (подробности — в плане).

`world-2` (отложен) запускается на порту 5174.

Расчёт на видеокарте (в работе, [план](../docs/plan/world-gpu-engine.md)): кнопка «Видеокарта» рядом со скоростью; проверка движка — страница `/engine-check.html`.
