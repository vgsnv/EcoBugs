# World 1 — архив

Прежняя CPU/Canvas-версия чашки. Сохранена для просмотра и сравнения; разработка прекращена. Совместимость с `world-2` не поддерживается. Архив не удаляется без отдельного решения пользователя.

Запуск из корня репозитория:

```sh
npm --prefix world-1 ci
npm --prefix world-1 run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Развиваемый мир находится в `world-2`, порт 5174.
