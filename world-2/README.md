# Мир EcoBugs

> Отложено (2026-10-04): разработка сосредоточена на `world-1`; эта версия сохранена для сравнения и не развивается.

Версия чашки с вычислениями и изображением на WebGPU. Совместимость кода, форматов сохранений и поведения с `world-1` не поддерживается.

Команды ниже выполняются из `world-2`.

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5174/. `npm run build` проверяет TypeScript и производственную сборку; `npm run check` — детерминированные генераторы, источники, воронки и целочисленный бюджет. Реальные GPU-проверки находятся в раскрываемом разделе «Диагностика GPU-кандидата».

Начальная сцена — полный мир по спецификации. Параметры задаются через «Создать новый мир». Доступны круг/прямоугольник, камера, миникарта, линейки, полный экран, диагностические карты, скрываемая сводка и ускорение. Проверочные сцены используют тот же движок.

Колесо и жест pinch меняют масштаб вокруг курсора; перетаскивание двигает карту, Shift + прокрутка — панорамирование. При приближении карта занимает всю область просмотра; кнопка «Вся чашка» возвращает общий вид.

Течения автоматически меняют вид со скоростью просмотра: ×1 — переносимая потоком рябь; ×10–100 — сглаженные стрелки; ×1000–10000 — сила и устойчивое направление со сглаживанием за 0,6 с просмотра. Меню «Течения» позволяет выбрать вид вручную. Движение штрихов условное, направление и яркость берутся из физического поля. На паузе показ стоит. «Процессы» подсвечивает среднюю скорость итоговых изменений грунта и залежей, а также уход в недра; встречные обмены между наблюдениями могут компенсироваться. Подробности и GPU-проверка солнечного течения — в [отчёте](../docs/reports/world-2-processes-2026-10-03.md).

Физический шаг 0,1 с. Минерал учитывается целыми квантами; квант выбирается при создании и не меняется. Обмены сохраняют дробные остатки и точную общую массу. Давление — SOR на стандартной сетке 128, многоуровневый метод на длинной стороне от 192 клеток; Jacobi оставлен для контрольного сравнения. Перенос и растекание выбирают внутренние подшаги по устойчивости, не меняя время мира. Выброс теряет собственный импульс, скользит и слабо отскакивает от стен, затем смешивается с поверхностным минералом.

Формат сохранения `ecobugs-gpu-2` содержит все продолжительные поля и автоматы. Старые CPU-файлы и экспериментальный `gpu-1` несовместимы. При потере устройства мир стоит; восстановление возвращает последнюю CPU-точку (снимок раз в 15 секунд реального хода), явно показывая её шаг. Не сохранённый промежуток не достраивается.

Крупные физические поля не читаются на CPU ради кадра. Редкие чтения обслуживают события, сводку, устойчивость и сохранения. Размер сетки и доступная память ограничивают комбинации параметров; слишком мелкие пятна либо неразрешимые доли отклоняются с понятным сообщением.

[Спецификация](../docs/spec/world.md), [план и решение о переходе](../docs/plan/world-gpu.md), [результаты измерений](../docs/reports/world-gpu-app-2026-10-03.md). Выигрыш подготовки изображения подтверждён; двукратное ускорение всей физики относительно прежней версии не подтверждено.
